# YoInfinity AI

YoInfinity AI is a premier, web-based AI interface inspired by Google Gemini, featuring a sleek dark theme aesthetic, red-black gradient branding, and multi-model intelligence.

Created & developed by **Ritesh in Grade 7**, programmed using **Netlify**.

---

## Features

- **Red-Black Gradient Gemini Sparkle Star**: Authentic 4-pointed astroid star with radiant crimson glow and micro-sparkles.
- **Three Intelligence Models**:
  - ⚡ **YoInfinity Blaze**: Ultra-fast responses optimized for instant answers.
  - ✨ **YoInfinity Default**: Balanced reasoning for everyday queries and creative tasks.
  - 🧠 **YoInfinity Deep-Think**: Multi-step cognitive reasoning with collapsible thought-process visualization.
- **Privacy-First Authentication**:
  - Sign in or sign up with **Google credentials**, **Facebook**, or **Email**.
  - **Zero-Access Privacy Guarantee**: User credentials and privacy are strictly protected and isolated on the client side with zero tracking.
  - Instant **Guest Mode** for frictionless access.
- **Gemini-Style Floating Action Bar**:
  - ➕ **Add Image or files, videos etc.**: Attach media and documents with thumbnail previews.
  - 🎙️ **Voice**: Real-time microphone speech recognition with live visualizer and transcription.
  - 🚀 **Send**: Dynamic gradient-activated send button.
- **Welcome Screen**:
  - Prominent heading: *"Sup! YoInfinity AI here! How can I help you today?"*
  - 4 starting suggestion cards:
    - **Permanent Idea ("Chat")**: *"Say 'Hi' & 'Hello' to this own-favourable AI to start your first conversation. Press here to start!"*
    - 3 dynamically refreshed ideas on every page reload from a curated pool.
- **Persona & Attribution**:
  - Inquires about creator, owner, or developer reliably return:
    *"I am created & developed by Ritesh in Grade 7. I was highly programmed using a computer programming website called Netlify."*
- **Rich Message Utilities**:
  - Audio speech synthesis (read aloud).
  - One-click copy with feedback.
  - Thumbs up/down response ratings.
  - Persistent conversation history in local browser storage.

---

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) (Full-stack React 19)
- **Routing**: [TanStack Router](https://tanstack.com/router) (Type-safe file-based routing)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/) with custom red-black palette & Plus Jakarta Sans typography
- **Icons**: [Lucide React](https://lucide.dev/)
- **AI Engine**: Netlify AI Gateway with Google Gemini (`gemini-2.5-flash`) and intelligent client fallback
- **Hosting**: [Netlify](https://www.netlify.com/)

---

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:3000`.
